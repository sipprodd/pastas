# Pastas

Pastas is a local clipboard manager for Windows 10/11, designed to be fast, privacy-first, and local-first.

## Vision
Provide a Spotlight-like clipboard history experience focused on local operation.

## Current status
This repository currently contains the **foundation phase** only:
- Initial project structure
- Architecture documentation
- MVP scope definition
- Minimal .NET 8 WPF solution scaffold

## Repository layout
- `src/Pastas` — WPF desktop application
- `tests/Pastas.UnitTests` — unit test project scaffold
- `docs` — architecture and MVP docs

## Principles
- Local-first by default
- Small, focused pull requests
- Layered architecture with clear boundaries
