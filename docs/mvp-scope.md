# Pastas MVP Scope

## In scope (MVP foundation)
- Repository structure for a .NET 8 WPF app
- Minimal runnable shell application (empty window)
- Basic project/test scaffolding
- Core architecture and scope documentation

## Out of scope (for this phase)
- Clipboard capture/monitoring logic
- SQLite or any persistence implementation
- Protected items and encryption workflows
- Notification/toast system
- Advanced UI features (search, preview, pinning, filtering)
- Cloud sync, remote APIs, telemetry backends
- Electron or web runtime stacks

## MVP direction (later, not now)
After the foundation phase, add features incrementally in small PRs:
1. Application and domain contracts
2. Clipboard ingestion flow
3. Local storage implementation
4. UX improvements and reliability hardening
